Escenarios de caso de uso

Según Metaute (2016) los casos de uso representan el sistema desde la perspectiva del usuario y deben cumplir varios objetivos: definir los requisitos funcionales y operativos del producto a través de un escenario acordado entre el usuario final y el equipo de desarrollo, ofrecer una descripción clara de la interacción entre el usuario y el sistema, y servir como base para la validación de pruebas.

Caso de uso Actor Descripción Flujo principal Flujo alternativo
Salir Usuario El usuario cierra sesión en el sistema. 1. Usuario selecciona "Salir".
2. El sistema cierra sesión.
3. Se redirige al login. 		El usuario cancela la acción y permanece en la aplicación.
Cancelar Usuario Permite abandonar una operación en curso. 1. Usuario presiona "Cancelar".
2. El sistema anula la acción.
3. Regresa a la pantalla anterior. 		El usuario decide continuar sin cancelar.
Crear Usuario Registrar nuevos datos en el sistema. 1. Usuario selecciona "Crear".
2. El sistema muestra formulario vacío.
3. Usuario llena datos.
4. El sistema guarda la información. 		Si hay datos inválidos, se muestra un mensaje de error.
Modificar Usuario Permite actualizar información ya registrada. 1. Usuario selecciona "Modificar".
2. Sistema muestra datos existentes.
3. Usuario edita campos.
4. Sistema guarda cambios. 		Si los cambios son inválidos, se cancela la modificación.
Consultar Usuario Permite visualizar datos almacenados. 1. Usuario selecciona "Consultar".
2. El sistema muestra la información disponible. 		Si no hay registros, se muestra mensaje "No existen datos".
Inhabilitar Administrador Desactiva un registro sin eliminarlo del sistema. 1. Administrador selecciona "Inhabilitar".
2. Sistema cambia estado del registro.
3. El registro no aparece en las consultas activas. 		Si el registro no existe, se muestra un mensaje de error.
